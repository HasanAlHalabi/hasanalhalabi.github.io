Quick Start

Your First 30 Days

Seven concrete steps to go from undecided to building in public.

  1. 1

    Pick your path

    Use the flowchart/quiz. Undecided + want max options/remote → Full-Stack (JS). Fastest first job → Frontend. Love systems/data + high pay → Backend. App-obsessed → Mobile (Flutter or React Native).

  2. 2

    Set up tools

    Install VS Code, Node.js, Git; create GitHub and LinkedIn profiles.

  3. 3

    Start one course and one habit

    Begin freeCodeCamp (free) or one flagship paid course (Angela Yu's bootcamp or Jonas's JS course); commit to a daily coding streak (10–15 hrs/week).

  4. 4

    Learn the fundamentals first

    HTML/CSS/JS or your language before any framework. Resist tutorial-hopping — for every hour of tutorial, build for 2–3 hours.

  5. 5

    Build in public

    Push every project to GitHub, deploy to Vercel/Netlify, and post progress.

  6. 6

    (Lebanon) Set up money + power early

    Open a fresh-USD account; create Wise + a crypto wallet + Purpl/Whish; sort backup power/internet — so you can accept remote work the moment you're ready.

  7. 7

    After ~3–4 projects, apply

    Polish your portfolio, write a focused CV, and start applying / bidding on Upwork while continuing to learn.

Realistic expectation: 6–12 months to job-ready with consistent effort. The market rewards a strong portfolio of real, deployed projects over certificates alone. Ship things, get feedback, iterate.

Built from the Fresh Graduate Developer Career Roadmap (2025–2026). Salary and market figures are 2024–2026 ranges; verify before relying on them.
